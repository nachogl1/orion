# Changelog

One file per pull request, named <YYYY-MM-DD>-<branch>.md (the branch name with / turned into -), holding one line: what changed and why it matters. Newest first: sort the names in reverse. The order is by the day an entry was written, not merged, and this README is not an entry.

Pull requests merged at the same time never touch the same file, so they never conflict. `docs/CHANGELOG.md` holds the entries from before this folder.
